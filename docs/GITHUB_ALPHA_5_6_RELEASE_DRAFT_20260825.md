# PeerBridge MCP v0.1.0-alpha.5.6

## English

Alpha 5.6 delivers the readable, responsive, three-language desktop prepared in the prior
candidates, with a verified first-launch fix and corrected signed provenance publication.

- A newly-created WebView2 profile now renders the Workbench on its first launch instead of
  requiring the user to close and reopen a blank window.
- Inactive Agents use compact status rows instead of black pseudo-terminal panels.
- Wrapped session cards cannot overlap Agent capability or managed-launch sections.
- Capability, permission, workflow, and launch controls use a more readable type scale.
- The right inspector becomes an on-demand drawer on narrower desktop windows.
- All four governed workflow names are localized in English, Traditional Chinese, and
  Simplified Chinese across selectors, operation records, and schedules.
- Windows remains a windowed desktop build; automatic probes and the managed supervisor do
  not open console windows.
- Release assets receive signed SLSA build-provenance attestations through the pinned
  official `actions/attest` v4.2.2 action.

This is a normal GitHub Release and is marked Latest. The product name remains Alpha to
describe its current compatibility and stability level accurately.

## 繁體中文

- 全新 WebView2 profile 第一次啟動即可顯示工作台，不再需要關閉白屏後重開。
- 未啟動 Agent 改用緊湊狀態列，不再顯示黑色假終端。
- 工作階段卡換行後，不會覆蓋 Agent 能力或受管啟動區塊。

- 較窄桌面視窗會把右側檢視器改成按需抽屜。
- 四個受治理工作流程名稱在選擇器、執行記錄與排程中均支援英文、繁中及簡中。
- Windows 維持無主控台桌面 build；自動探測及受管監督程序不會開啟終端視窗。
- 發佈資產由固定版本的官方 `actions/attest` v4.2.2 產生簽署 SLSA build provenance。

本版在 GitHub 屬一般 Release 並標記為 Latest；產品仍保留 Alpha 名稱，以如實表達目前的
