# PeerBridge MCP v0.1.0-alpha.5.4

## English

Alpha 5.4 is a desktop usability and localization maintenance release for the local
PeerBridge workspace.

- Inactive Agents now use compact status rows instead of black pseudo-terminal panels.
- The multi-Agent console no longer lets wrapped session cards overlap the capability and
  managed-launch sections.
- Agent capability, permission, workflow, and launch controls use a more readable desktop
  type scale.
- The right inspector becomes an on-demand drawer on narrower desktop windows, preserving
  room for the primary workspace without removing the inspector.
- Implement and Review, Investigate and Debate, Read-only Audit, and Release Gate are fully
  localized in English, Traditional Chinese, and Simplified Chinese.
- Windows remains a windowed desktop build; automatic Agent discovery and the managed
  supervisor continue to run without opening console windows.

This is a normal GitHub Release and is marked Latest, while the product name remains Alpha
to describe its current compatibility and stability level accurately.

## 繁體中文

Alpha 5.4 是 PeerBridge 本機工作區的桌面可用性與本地化修正版。

- 未啟動的 Agent 改用緊湊狀態列，不再顯示黑色假終端。
- 多智能體控制台的工作階段卡換行後，不會再覆蓋能力與受管啟動區塊。
- Agent 能力、權限、工作流程與啟動控制採用更容易閱讀的桌面字級。
- 較窄的桌面視窗會把右側檢視器改成按需抽屜，保留主要工作區寬度但不移除功能。
- 「實作與審查、調查與討論、唯讀審計、發佈閘門」已完整支援英文、繁中與簡中。
- Windows 仍使用無主控台桌面 build；自動 Agent 探測及受管監督程序不會開啟終端視窗。

本版在 GitHub 屬一般 Release 並標記為 Latest；產品仍保留 Alpha 名稱，以如實表達目前的
相容性與穩定程度。

## 简体中文

- “实施与审查、调查与讨论、只读审计、发布闸门”已完整支持英文、繁中和简中。
- Windows 仍使用无控制台桌面 build；自动 Agent 探测和受管监督进程不会打开终端窗口。

本版本在 GitHub 中属于普通 Release 并标记为 Latest；产品仍保留 Alpha 名称，以如实表达
当前的兼容性和稳定程度。
